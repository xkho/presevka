## Iosevka

- Repository: https://github.com/be5invis/Iosevka
- Pinned version: v34.9.0
- Copyright: Copyright (c) 2015-2026, Renzhi Li (aka. Belleve Invis)
- License: SIL Open Font License 1.1
- Reserved Font Names: none declared in the pinned version's `LICENSE.md`

Presevka builds Iosevka with its default 500/1000-em unit width and its stock
character variants; no stylistic set or character variant is overridden.

## Pretendard

- Repository: https://github.com/orioncactus/pretendard
- Pinned version: v1.3.9
- Copyright: Copyright (c) 2021, Kil Hyung-jin, together with the respective
  authors of the upstream Source, Inter, and M PLUS 1 glyph designs
- License: SIL Open Font License 1.1
- Reserved Font Name declared by the pinned Pretendard license: `Pretendard`

Presevka also conservatively preserves the copyright, trademark, and Reserved
Font Name notices associated with Pretendard's acknowledged upstream designs:
`Source`, `Inter`, and `M PLUS 1`. None of these names is used as Presevka's
primary font name.

Pretendard's nine static weights supply the corresponding Hangul outlines.
Presevka converts them to TrueType outlines when needed, normalizes them to a
1000-unit em, enlarges every Hangul outline horizontally by 2% around its
center, places strict Hangul in a 1000-unit advance, and merges it into the
matching Iosevka base.

## Adwaita Fonts (optional build preset only)

- Repository: https://gitlab.gnome.org/GNOME/adwaita-fonts
- Copyright: Copyright (c) 2025, Jamie Gravendeel and Florian Müllner, together
  with the Inter Project Authors and Renzhi Li as recorded in that project's
  `LICENSE`
- License: SIL Open Font License 1.1
- Reserved Font Names: none declared in that project's `LICENSE`

`config/presets/adwaita-mono.toml` reproduces the character-variant selection
GNOME's Adwaita Mono makes, because Adwaita Mono is an Iosevka build shaped
toward Inter and Pretendard's Latin is Inter-derived as well.

No Adwaita glyph outline is included in Presevka, under this preset or any
other. The preset only chooses among glyph designs Iosevka already draws, and
it changes nothing else: Presevka keeps its own 500-unit cell, `normal`
spacing, character-variant features and nine weights, where Adwaita Mono uses
a 600-unit cell, `fixed` spacing, `noCvSs` and two weights. Released builds
use the stock Iosevka variants; this preset is opt-in via `PRESEVKA_PRESET`.

## ttfautohint

- Project: https://freetype.org/ttfautohint/
- Engine version embedded by `ttfautohint-py` 0.6.1: ttfautohint 1.8.4
- License: the ttfautohint program is dual-licensed under the FreeType License
  and GPLv2; see the project's own licensing terms for how they apply to
  generated hinting code.

Unless `PRESEVKA_HINT=none` is used, the shipped fonts contain TrueType hinting
bytecode generated by ttfautohint in their `fpgm`, `prep`, `cvt ` and `glyf`
tables. No ttfautohint source code or glyph design is included. See
`FONTLOG.md` for which build stage applies it.
