한 칸의 약속

한글이 라틴 두 글자의 폭을 정확히 차지합니다. 주석에 한국어를 써도 표의 세로줄과 들여쓰기가 어긋나지 않습니다.

아홉 굵기

Thin 100부터 Black 900까지

모든 굵기에서 한글 획을 라틴에 맞춰 그렸습니다. 한 음절에 자모가 여럿 들어가 같은 굵기면 더 검게 보이므로, 한글은 라틴보다 조금 얇게 둡니다.

Iosevka의 것을 그대로

글자꼴을 골라 쓰세요

라틴은 Iosevka를 손대지 않고 씁니다. 그래서 stylistic set 19종과 character variant 99종이 폰트 안에 들어 있고, 다시 받거나 빌드하지 않아도 에디터 설정만으로 켜집니다.

쓰시는 코드를 붙여 넣어 보세요. 글꼴은 자기 글을 쳐 봐야 판단이 섭니다.

#include <vector> // 읽은 값들의 평균. 빈 배열이면 0을 돌려준다 double average(const std::vector<double>& readings) { double sum = 0.0; int count = 0; // 나중에 거를 조건을 넣을 수 있게 size() 대신 직접 센다 for (double c : readings) { sum += c; ++count; } return count > 0 ? sum / count : 0.0; // 0으로 나누지 않도록 막는다 }
